# DVWA-2026-Portfolio

## 프로젝트명
DVWA 취약점 분석 및 웹 서버 모의해킹 시나리오

## 담당 역할
- Part I: Brute Force, CSRF (Low~Impossible 레벨별 실습)
- Part II: 상대 조 웹사이트 대상 CSRF 공격 수행 (소스코드 분석 → 취약점 분석 → 공격)

## 업무 기간
2026.03.09 ~ 2026.03.20 (팀 프로젝트, 6인 중 담당 파트)

## 사용 기술
Kali 2024-2, Rocky 9.6/Rocky 10, Burp Suite, Python3

## 상세 내용
Part I에서는 DVWA 13개 취약점 항목을 팀원 3인이 분담해 Low~Impossible 레벨별로 실습했으며, 본인은 Brute Force와 CSRF를 담당했습니다. Part II에서는 신규 웹 서버 오픈 전 보안 점검을 의뢰받은 가상 시나리오로 상대 조 웹사이트에 대해 CSRF 공격을 수행했습니다.
